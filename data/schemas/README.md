# Data Schemas

This directory is reserved for schemas that describe curated, generated, or
import-related data contracts. Keep each schema versioned, documented, and
separate from individual source records.

The source registry's schema lives beside its registry in data/sources/ because
it is the registry's immediate contract.

`pob-neutral-import-v1.schema.json` describes the adopted version `1.0.0` PoB
neutral intake result. It is deliberately separate from the future Golden Glory
Lab saved-build schema.
