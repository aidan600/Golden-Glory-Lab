# Start a Golden Glory Lab audit

Use this command to start a bounded, source-backed audit. Read AGENTS.md,
docs/SOURCE_POLICY.md, docs/AUDIT_WORKFLOW.md, and docs/audits/TEMPLATE.md
before researching.

Collect or request the following before treating the audit as active:

    Mode: AUDIT
    Audit ID and title:
    Question:
    Product impact:
    Scope:
    Source plan:
    Expected dataset impact:
    Constraints:
    Deliverables:
    Verification requirements:

Create the audit record from the template, register each material source in
data/sources/registry.json, distinguish evidence from inference, preserve
conflicts and version mismatch, and state non-conclusions. Do not start a Path
of Exile mechanics audit merely because a possible source has been found.
