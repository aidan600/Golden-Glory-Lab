# Historical and Supporting Reference Material

Everything under docs/reference/ is noncanonical. It may contain useful leads,
source links, abandoned architecture ideas, outdated schemas, or superseded
scope. Agents may consult it, but must follow underlying sources and the
current documentation.

No conclusion becomes current merely because it is copied from historical
research. Record a current audit, source registry entry, or decision as
appropriate. Historical roadmaps and abandoned plans kept here must not be
treated as current instructions; see
[CURRENT_STATE.md](../CURRENT_STATE.md) and
[SPEC_STATUS.md](../SPEC_STATUS.md).

The [initial-research directory](initial-research/README.md) contains preserved
material supplied with a task, if any.
