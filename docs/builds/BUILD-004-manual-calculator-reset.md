# BUILD-004 - Manual Golden Glory Calculator Product Reset

Mode: BUILD

Date: 2026-08-06

Status: implemented (pending merge)

## Outcome

The ordinary desktop product is now a manual-first two-page **Golden Glory
Calculator**:

1. Calculator — Luminary and Mercenary/Enmity inputs with live results
2. Light Radius Breakdown — optional slot/jewel totals that can be applied to
   the Calculator page

PoB import, item mapping/review, build-state persistence, evidence UI, and the
diagnostic `GoldenGloryApp` remain in the repository as experimental
infrastructure. They are not required by the calculator and are not the default
launch path.

The calculator does not report DPS. It reuses the existing Flame Link evaluator
and packaged level table through a narrow `manual_calculator` domain seam, and
shares one Enmity overcap helper with the BUILD-002 evaluator.

## Fractional Fire Resistance

The Enmity section truncates the post-reduction resistance total toward zero
before subtracting the maximum, matching current Path of Building behaviour:

    final_uncapped = truncate_toward_zero(pre_enmity * (1 - reduced_pct / 100))
    overcapped     = max(0, final_uncapped - maximum)
    penetration    = min(200, overcapped)

The displayed Final Uncapped Fire Resistance is the truncated integer actually
used by the calculation. A fractional intermediate no longer blocks the result.
Verification status for the truncation rule is provisional: it reproduces
current PoB behaviour and is not yet backed by an official source.

## Light Radius slots

The breakdown page covers Helmet, Body Armour, Boots, Main Hand, Off Hand,
Amulet, Ring 1, Ring 2, Belt, Passive Tree / Ascendancy, Other / Misc, and
jewels. Gloves are excluded because no current Light Radius source was found on
that slot. Slot values themselves remain unvalidated manual planning entry.

## Presentation

The window is fixed at 1024x856 and non-resizable, so neither tab can clip or
scroll. The height is sized for the worst case, where every derived resistance
line and both validation messages are visible at once, and a regression test
asserts that neither page needs more height than it has. Both pages are laid out as a titled card containing bordered sections
with an 18 px inner gutter, dark charcoal body text, and warm gold reserved for
headings, accents, and result values.

Slot, jewel, tab, action, and checkbox-indicator artwork ships as small PNGs in
`golden_glory_lab.desktop.icons`, generated by
`scripts/generate_breakdown_icons.py` (Pillow, drawn at 8x and downsampled).
The icons are decorative only; every row keeps its text label.

## Packaging

`scripts/build_calculator_exe.py` builds a one-file
`GoldenGloryCalculator.exe` with the pinned PyInstaller packaging environment.
The existing one-directory packaging validation machinery remains intact.
